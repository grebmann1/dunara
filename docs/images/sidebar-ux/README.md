# Project sidebar

The sidebar follows the supplied Command Center reference: simple icon rows, neutral selection, a searchable Projects section with colored project markers, and Settings at the bottom. The project header retains a quick switcher. Desktop width is adjustable with a pointer or keyboard.

Actual screenshots from disposable fixtures were opened and inspected at [1440 × 1000](desktop.png), [375 × 812](phone-375.png), and [430 × 932](phone-430.png). On phones, the header switcher replaces the full project list and navigation uses compact rows. No user projects or credentials appear in these images.

Behavior coverage includes filtering by name and slug, same-name disambiguation, keyboard activation, collapsing Projects, scrolling a long project list, pinned Settings, drag/keyboard resize and reset, project switching with the sidebar hidden, phone controls and 200% zoom.
