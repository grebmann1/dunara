Screenshots from disposable browser fixtures at 1440 × 1000 and 375 × 812. The preview is intentionally stopped and the fixture has no Assistant provider. These images contain no user projects or provider credentials.

- [Workspace](workspace-desktop.png): a slim journey strip leaves the canvas visible; the header, navigation and desktop controls use less space.
- [Ideate on desktop](ideate-desktop.png): a focused guidance panel with a brief field, one primary continuation action and secondary planning.
- [Ideate on a phone](ideate-phone.png): the same stages and form fit a compact viewport, with larger touch targets.
- [Backend before creation](backend-before-creation.png): choose Supabase and save the account connection before creating the local workspace, or explicitly continue without a backend. Project selection and remote changes remain separately reviewed in Backend.

The stages are Ideate → Connect Supabase → Create → Add assets → Preview & test → Build → Publish. Closing the guide preserves its unsaved brief during the session and leaves the canvas in place.
