# Mobile Builder visual review

Read and follow the shared instructions at [the canonical visual-review skill](../../../.agents/skills/mobile-builder-visual-review/SKILL.md), relative to this file. Keep that file as the single source of the detailed workflow.

Throughout UI work, capture after first render, meaningful visual changes or small UI batches, and before handoff. Inspect the actual PNG, make focused changes, then recapture the same route/size/appearance/state. If the model cannot see the image, report visual review blocked rather than describing metadata as visual evidence. This is on-demand guidance, not automatic screenshot delivery.
